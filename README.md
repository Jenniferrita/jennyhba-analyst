# Jennifer Onyekwere portfolio

Static site (no build step).

Open in Visual Studio Code:
1. File > Open Folder, choose this folder.
2. Install the "Live Server" extension, right-click index.html and choose "Open with Live Server" to preview.

Publish: upload the contents of this folder to Netlify, GitHub Pages or Cloudflare Pages (free, no watermark).

Replace Jennifer-Onyekwere-Resume.pdf whenever your resume changes.
